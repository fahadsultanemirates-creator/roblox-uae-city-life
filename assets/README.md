# Visual reference assets

The visual references are currently included in the downloadable **Roblox_UAE_City_Life_Starter.zip** shared in the ChatGPT conversation, but the original PNGs have **not yet been uploaded into this GitHub repository**.

Reference filenames from that package:
- `game_thumbnail_concept.png` — rainbow owner avatar, UAE city skyline and all three emergency vehicles.
- `emergency_vehicles_concept.png` — close-up Roblox-style preview of the police SUV, ambulance and yellow fire engine.

These are pictures for design guidance; **PNG pictures do not turn into drivable Roblox models automatically**. The map generator builds approximate 3D vehicles from Roblox Parts instead.

To add the image files here later: open this `assets` directory on GitHub, choose **Add file > Upload files**, select the two PNGs from the starter ZIP, and commit. To use a thumbnail inside Roblox, upload it separately through the Roblox Creator Dashboard.

Never upload account passwords, tokens, or private information.
